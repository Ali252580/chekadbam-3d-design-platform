# صفحهٔ فرود روف‌گاردن برای المنتور

دو فایل در این پوشه:

| فایل | کاربرد |
|---|---|
| `elementor-template.json` | قالب کامل صفحهٔ فرود روف‌گاردن — قابل ایمپورت مستقیم در المنتور |
| `index.html` | پیش‌نمایش طراحی بدون وردپرس (برای دیدن نتیجهٔ نهایی در مرورگر) |

## شناسهٔ طراحی

- پالت: سبز جنگلی برند `#1D3B2A` + چوب WPC `#C0903F` + کاغذی `#F2F4EC`
- فونت تیترها: **Lalezar** — فونت متن: **Vazirmatn** (هر دو از Google Fonts؛ المنتور خودکار پیدا می‌کند)
- عنصر امضا: «برش لایه‌های بام» — شماتیک ۶ لایه (ایزولاسیون ← پایه ← عایق ← زه‌کشی ← خاک ← کاشت) که با ویجت HTML ساخته شده؛ ظاهرش مستقل از قالب سایت است.
- ۸ سکشن: هیرو ← لایه‌ها ← ۵ مرحله ← استودیوی سه‌بعدی ← محصولات ← گالری پروژه ← FAQ (ویجت Toggle) ← CTA پایانی

## مراحل ایمپورت

1. **پیشخوان → Templates → Saved Templates → Import Templates** (دکمهٔ بالا-چپ)
2. فایل `elementor-template.json` را انتخاب و آپلود کنید.
3. از فهرست قالب‌ها، «روف گاردن — چکادبام» را **Edit with Elementor** باز کنید (یا برای صفحهٔ جدید: New Page → … → My Templates → Add Template).
4. **Publish** و URL صفحه (پیشنهاد: `/roof-garden/` یا `/روف-گاردن/`) را تنظیم کنید.

> فونت‌ها: بار اول که Elementor فایل را باز می‌کند، Lalezar و Vazirmatn را از Google Fonts لود می‌کند. اگر میزبانی ایران مشکل دارد، both فونت‌ها را از قبل در Elementor → Site Settings → Global Fonts تعریف کنید.

## لینک‌هایی که باید بررسی/جایگزین شود

| آیتم | مقدار فعلی | جایگزین پیشنهادی |
|---|---|---|
| دکمهٔ استودیو (۳ جا: هیرو، استودیو، کارت پلان، CTA پایانی) | URL حدسی `…/چکادبام-استودیو/` | آدرس واقعی استودیوی سه‌بعدی که در تولید است |
| شمارهٔ تماس | `tel:09121306522` | اگر قرار است فرم مشاوره جایگزین شود، فرم مشاوره |
| کارت‌های محصول | فلاورباکس / پرگولا / مبلمان — لینک واقعی صفحات سایت | بدون تغییر لازم |
| تصاویر | همگی هات‌لینک از `chekadeno.com/wp-content/uploads/…` | بهتر است پس از ایمپورت در کتابخانهٔ رسانه آپلود شوند (کلیک روی تصویر → Choose Image → Media Library) |

## سئوی صفحهٔ جدید

- **Title:** `اجرای روف گاردن پرتابل-مدولار | بدون سوراخکاری | چکادبام`
- **Meta:** `اجرای روف گاردن به روش پرتابل-مدولار در ۵ مرحله: بازدید و طراحی، ایزولاسیون، تولید و حمل، اجرای سازه و کاشت؛ همراه جدول لایه‌بندی، نکات زهکشی و بار مجاز سازه.`
- در Yoast/Rank Math این دو را دستی وارد کنید؛ قالب `hide_title` دارد و عنوان صفحه دیده نمیشود.
- تصویر شاخص: `2022/05/04.jpg.webp`
- اگر صفحهٔ مقالهٔ «جزئیات اجرایی روف گاردن» را نیز بهینه می‌کنید، لینک دوسویه بین این صفحهٔ فرود و مقاله ایجاد کنید.
