# چکادبام — پلتفرم طراحی سه‌بعدی روف‌گاردن (Chekadbam 3D Design Platform)

پلتفرم طراحی و فروش سیستم‌های مدولار چوب‌پلاست روف‌گاردن، شامل دو بخش اصلی:

1. **استودیوی طراحی سه‌بعدی Next.js** (`src/`) — اپلیکیشن کامل با پنل مدیریت، کاتالوگ محصولات، CRM طرح‌ها و استودیوی سه‌بعدی
2. **افزونه وردپرس چکادبام استودیو** (`wordpress-plugin/`) — پورت کامل و مستقل از استودیو به‌صورت vanilla JS بدون نیاز به build

---

## ۱) استودیوی Next.js

### اجرای محلی

```bash
npm install
npm run dev        # http://localhost:3100
```

### امکانات

- استودیوی سه‌بعدی واقع‌گرایانه با ۱۶ مدل محصول مدولار (پرگولا، ست مبل، آبنما، آتشدان، دیوار سبز و …)
- موتور بافت رویه‌ای چوب‌پلاست/پارچه/چمن + موتور گیاه‌شناسی (برگ، گل، تاج درخت)
- نورپردازی روز / غروب / شب با سایه‌های PCF و ACES tone mapping
- ۶ فرم پلان (مستطیلی، L، U، باکس پله، تراس طولی، پنت‌هاوس دوبالکه) با ابعاد دلخواه
- محدودسازی مرزی هوشمند با احتساب چرخش و فرورفتگی‌ها (`src/lib/plan-boundary.ts`)
- Undo/Redo (۵۰ مرحله)، اسنپ شبکه‌ای، میانبرهای کیبورد
- فهرست اقلام (BOM) محاسباتی: متراژ، ایمنی سازه، بازه قیمت تومانی
- ثبت طرح با اسکرین‌شات + پنل CRM طرح‌ها + همگام‌سازی با افزونه وردپرس

### همگام‌سازی طرح‌ها از وردپرس

افزونه وردپرس طرح‌های ثبت‌شده را به اندپوینت `/api/designs/wordpress` این پنل ارسال می‌کند.
توکن مشترک از طریق متغیر محیطی `DESIGN_SYNC_TOKEN` تنظیم می‌شود (باید با توکن تنظیمات افزونه یکی باشد).

---

## ۲) افزونه وردپرس — چکادبام استودیو منیجر (نسخه 2.7.3)

مسیر: `wordpress-plugin/chekadbam-studio/` — بسته نصبی: `wordpress-plugin/chekadbam-studio.zip`

استودیوی کامل سه‌بعدی، هم‌تراز با نسخه Next.js، به‌صورت vanilla JS (بدون وابستگی CDN؛ Three.js لوکال).

### نصب

1. پیشخوان وردپرس → افزونه‌ها → افزودن → بارگذاری افزونه → آپلود `chekadbam-studio.zip`
2. فعال کنید؛ منوی «چکادبام استودیو» ساخته می‌شود و اقلام/پلان‌های نمونه درج می‌شوند

### شورت‌کدها

| شورت‌کد | کاربرد |
|---|---|
| `[chekadbam_studio]` | استودیوی کامل طراحی (تمام‌صفحه؛ خروج: `fullscreen="0" height="88vh"`) |
| `[chekadbam_3d code="CK-PG-DK320"]` | نمایشگر سه‌بعدی یک محصول |
| `[chekadbam_3d_gallery category="planting"]` | گالری سه‌بعدی محصولات |
| `[chekadbam_form]` | فرم ثبت درخواست مشاوره |

### امکانات کلیدی افزونه

- استودیوی سه‌بعدی با مدل‌های واقعی محصولات، بافت‌های رویه‌ای و انیمیشن‌های زنده (آب ریزان، شعله، کاستیک آب)
- نمای پشت‌بام: ساختمان میزبان با پنجره‌هایی که در شب روشن می‌شوند + همسایه‌ها و خیابان
- محدودسازی مرزی پلان (هیچ قلمی از دیوار یا فرورفتگی خارج نمی‌شود؛ قلم جا نشده با پیام واضح وسط پلان قرار می‌گیرد)
- نوار قلم انتخاب‌شده: جابه‌جایی نیم‌متری (دکمه و کلید جهت‌دار)، چرخش ۴۵°/۹۰°، تکثیر، رنگ چوب‌پلاست، نمایش مختصات
- کاتالوگ با جستجو، فیلتر دسته‌بندی و بندانگشتی سه‌بعدی زنده (موتور رندر مشترک برای کارایی موبایل)
- Undo/Redo، هشدار همپوشانی (فقط برای همپوشانی‌های ساخت کاربر)، راهنمای استودیو + تور تصویری نقشه
- حالت موبایل بهینه: سقف ۳۰ فریم، منوی جمع‌شونده «⌄»، محو خودکار منو هنگام کشیدن قلم، بدون backdrop-blur
- فهرست اقلام (BOM) با متراژ و ایمنی سازه + دکمه چاپ
- ثبت طرح با اسکرین‌شات JPEG (پیش‌نمایش و دانلود تصویر) + کد پیگیری + ارسال خودکار به پنل Next.js
- REST API هم‌خوان با پنل: `GET /products`، `GET /plans`، `POST /designs`، `GET /designs` (namespace: `chekadbam/v1`)

### اتصال به پنل (همگام‌سازی طرح‌ها)

پیشخوان → چکادبام استودیو → تنظیمات → «اتصال به پنل»: آدرس پنل + توکن (باید با `DESIGN_SYNC_TOKEN` پنل یکی باشد) + دکمه تست اتصال.

### تست بدون وردپرس

```bash
cd wordpress-plugin
python -m http.server 8899
# سپس در مرورگر: http://localhost:8899/chekadbam-studio/test-page.html
```

صفحه `test-page.html` کل استودیو، ویرایشگر قلم با پیش‌نمایش زنده و سه نمایشگر محصول را با داده mock اجرا می‌کند.

## ساختار مخزن

```
src/                     اپلیکیشن Next.js (استودیو، پنل، API)
wordpress-plugin/        افزونه وردپرس + بسته نصبی zip
migrations/              مهاجرت‌های دیتابیس (drizzle)
```

## نکته استقرار افزونه

اگر هنگام نصب خطای «پرونده افزونه پیدا نشد» دیدید: پوشه قدیمی `chekadbam-studio` (و `chekadbam-studio-1`) را از `wp-content/plugins` حذف و افزونه را دوباره نصب کنید. zip با ساختار پوشه درست و اسلش رو به جلو ساخته می‌شود — از `Compress-Archive` ویندوز برای ساخت مجدد آن استفاده نکنید.
