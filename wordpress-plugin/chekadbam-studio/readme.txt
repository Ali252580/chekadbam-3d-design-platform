استودیوی طراحی سه‌بعدی واقع‌گرایانه روف‌گاردن با مدل‌های واقعی محصولات — مدیریت اقلام مدولار چوب‌پلاست، پلان‌ها، CRM طرح‌ها، REST API، نمایشگر سه‌بعدی محصول و کد کوتاه فرم.

== ویژگی‌ها ==

۱) استودیوی طراحی سه‌بعدی v2 (هم‌تراز با استودیوی Next.js):
* مدل‌های سه‌بعدی واقع‌گرایانه ۱۶ محصول: پرگولا با دک کف، ست مبل، نیمکت شیاردار، درخت با تاج برگ‌به‌برگ، آبنمای دوقاب با آب متحرک، میز آتشدان با شعله، چتر هیدرولیک پایه‌کنار، دیوار سبز با پیچک واقعی، باربیکیو، لوور و ...
* بافت‌های رویه‌ای چوب‌پلاست شیاردار (map + bump + roughness)، پارچه سان‌برلا و چمن مصنوعی
* موتور گیاه‌شناسی: برگ‌های منحنی رگ‌دار، گل‌های ۵ پر با پرچم طلایی، تاج درخت چندلایه
* نورپردازی روز / غروب / شب با سایه‌های PCF و ACES tone mapping
* محدودسازی مرزی پلان با احتساب چرخش و فرورفتگی‌ها (هیچ قلمی از دیوار خارج نمی‌شود)
* شخصی‌سازی کامل پلان: ۶ فرم (مستطیلی، L، U، باکس پله، تراس طولی، پنت‌هاوس دوبالکه)، ابعاد دلخواه، رنگ WPC/فلز، نوع کف‌سازی
* Undo/Redo (۵۰ مرحله)، جابه‌جایی ریز نیم‌متری با دکمه‌های جهت‌دار نوار قلم و کلیدهای جهت‌دار، تکثیر و رنگ مستقل هر قلم
* میانبرهای کیبورد: Delete حذف، Ctrl+Z/Y تاریخچه، R چرخش، کلیدهای جهت‌دار جابه‌جایی، Escape لغو انتخاب
* کاتالوگ اقلام با جستجو و فیلتر دسته‌بندی + پیش‌نمایش سه‌بعدی زنده هر قلم
* فهرست اقلام (BOM) محاسباتی: وزن کل، وزن بر مترمربع، ایمنی سازه، بازه قیمت تومانی + چاپ فهرست
* ثبت طرح با اسکرین‌شات JPEG از صحنه سه‌بعدی (پیش‌نمایش و دانلود تصویر در پنجره ثبت، ذخیره در رسانه و متا، کد پیگیری)
* هشدار همپوشانی اقلام + قطب‌نما + راهنمای تعامل

۲) نمایشگر سه‌بعدی محصول (جدید):
* شورت‌کد [chekadbam_3d code="CK-FB-160"] برای نمایش مدل سه‌بعدی هر محصول در هر صفحه
* شورت‌کد [chekadbam_3d_gallery category="planting"] برای گالری محصولات
* متاباکس «پیش‌نمایش سه‌بعدی محصول» در صفحه ویرایش قلم
* چرخش با درگ، زوم با اسکرول، چرخش خودکار در حالت بی‌کاری

۳) اقلام مدولار:
* افزودن/ویرایش/حذف قلم با کد فنی، دسته‌بندی، نوع شکل سه‌بعدی (۱۶ شکل)
* سه فیلد مجزای طول، عرض و ارتفاع (متر) + وزن، قیمت، رنگ چوب‌پلاست/فلز و نورپردازی
* ستون‌های جدول مدیریت و جستجو/فیلتر

۴) پلان‌های نقشه:
* فرم‌های مستطیلی، L شکل، U شکل، باکس پله مرکزی، تراس طولی
* چیدمان اقلام روی پلان با ردیف‌های تکرارشونده و محاسبه خودکار متراژ خالص

۵) طرح‌های ثبت‌شده (CRM):
* ذخیره خودکار طرح‌های ارسالی استودیو/فرم با تصویر پیش‌نمایش
* ذخیره BOM (وزن، ایمنی سازه، بازه قیمت) و مشخصات کامل پلان در متا
* ستون تصویر در لیست طرح‌ها + وضعیت پیگیری + فیلتر وضعیت + یادداشت کارشناس
* ایمیل اطلاع‌رسانی غنی‌شده با متراژ/وزن/قیمت

۶) ارسال خودکار طرح‌ها به پنل (جدید):
* هر طرح که در وردپرس ثبت می‌شود (استودیو، REST یا فرم مشاوره) بلافاصله به اندپوینت /api/designs/wordpress پنل Next.js ارسال می‌شود
* تنظیمات: پیشخوان → چکادبام استودیو → تنظیمات → «اتصال به پنل» (آدرس پنل + توکن + دکمه تست اتصال)
* احراز هویت با توکن مشترک (هدر X-CKB-Token) که باید با متغیر محیطی DESIGN_SYNC_TOKEN پنل یکی باشد
* جلوگیری از ثبت تکراری در پنل با شناسه طرح وردپرس (sourceRef)
* ستون «ارسال به پنل» در فهرست طرح‌ها + دکمه «ارسال مجدد» در صفحه ویرایش طرح

۷) دیگر:
* REST API هم‌خوان با استودیوی Next.js (_NAMESPACE: chekadbam/v1)
* کد کوتاه فرم: [chekadbam_form]
* داده‌های نمونه + کاملاً راست‌چین و فارسی + بدون وابستگی CDN (Three.js لوکال)

== نصب ==

۱. فایل chekadbam-studio.zip را از پیشخوان وردپرس → افزونه‌ها → افزودن → بارگذاری افزونه، آپلود و نصب کنید
   (یا پوشه chekadbam-studio را در wp-content/plugins/ قرار دهید).
۲. افزونه را فعال کنید؛ منوی «چکادبام استودیو» ظاهر می‌شود و اقلام/پلان‌ها/طرح‌های نمونه درج می‌شوند.
۳. از منوی «استودیوی طراحی ۳D بام» وارد استودیو شوید یا شورت‌کد [chekadbam_studio] را در هر صفحه قرار دهید.
۴. برای نمایش مدل سه‌بعدی محصول در صفحات: [chekadbam_3d code="کد محصول"]
۵. برای گالری سه‌بعدی محصولات: [chekadbam_3d_gallery]

== REST API (هم‌خوان با استودیو Next.js) ==

Namespace: /wp-json/chekadbam/v1

هر دو فرانت‌اند (استودیوی Next.js و افزونه وردپرس) از یک فرمت داده مشترک استفاده می‌کنند:

* GET  /products — فهرست اقلام با ساختار ChekadbamProduct شامل dimensions{width,depth,height,unitString}، weightKg، deadLoadRating، priceEstToman، materials{wpcColors,metalColors} و model3D{shapeType,primaryColor,secondaryColor,hasLighting} (عمومی)
* GET  /plans    — فهرست پلان‌ها با ساختار SpaceConfig + StudioItem[] شامل spaceConfig{shape,width,length,parapetHeight,flooringType,wpcColor,metalColor,cutoutWidth,...} و آیتم‌های استاندارد {id,productId,x,z,rotation,width,depth,height,shapeType,...} (عمومی)
* POST /designs  — ثبت طرح؛ بدنه Next.js (userName, userPhone, layoutData, totalArea, estimatedWeightKg, estimatedPriceMin/Max, snapshotUrl) و بدنه قدیمی (name, phone, items, snapshot) هر دو پذیرفته می‌شود؛ پاسخ شامل design.id و id (عمومی)
* GET  /designs  — فهرست طرح‌ها با نام فیلدهای Next.js (userName, layoutData, snapshotUrl, estimatedPriceMin/Max, ...) + نام‌های قدیمی (فقط مدیر)
