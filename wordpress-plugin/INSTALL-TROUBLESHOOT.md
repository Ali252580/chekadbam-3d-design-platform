## سه علت باقی‌مانده و راه‌حل (به ترتیب احتمال)

### 1. باقی‌مانده نصب خراب قبلی (شایع‌ترین)
نسخه‌های قبلی زیپ (STORE/پوشه تودرتو) ممکن است پوشه‌ای نیم‌نصج در سرور گذاشته باشند.
وردپرس پوشه موجود را می‌بیند، ولی فایل اصلی داخلش خراب است → «شناسایی نمی‌شود».

**رفع:** با FTP/file-manager هاست بروید به `wp-content/plugins/` و پوشه‌های زیر را پاک کنید:
- `wp-content/plugins/chekadbam-studio/` (اگر محتوای خراب دارد)
- `wp-content/plugins/chekadbam-studio-1/` (اگر وجود دارد)
سپس دوباره افزودن افزونه → بارگذاری زیپ.

### 2. آپلود فایل zip قدیمی از حافظه مرورگر
شاید مرورگر همان زیپ قدیمی را کش کرده و دوباره آپلود می‌کند.
**رفع:** زیپ جدید را دوباره از `$USER\Downloads\chekadbam-3d-design-platform1\wordpress-plugin\chekadbam-studio.zip` دانلود و در پیشخوان بارگذاری کنید.

### 3. محدودیت آپلود هاست
اگر پیام موقت می‌آید یا ریسپانص کامل نمی‌شود: `php.ini` هاست؛
`upload_max_filesize` و `post_max_size` را بالای ۲۵MB بگذارید (به ادمین هاست بگویید).

## تست قطعی سالم بودن zip (اختیاری)
روی سیستم خودتان:
```
cd chekadbam-3d-design-platform1/wordpress-plugin
unzip -t chekadbam-studio.zip
# باید «31 files, No errors detected» باشد
```
